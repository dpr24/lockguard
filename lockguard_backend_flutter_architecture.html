3. Google Sign-In & User Lifecycle Architecture

Seamless, passwordless authentication using Google OAuth 2.0 OpenID Connect ID Tokens verified on Laravel.

Zero-Password Architecture
Client-Side Flutter Auth Flow

The user taps "Continue with Google". The Flutter application uses the official google_sign_in plugin to initiate the native Android Account Manager intent. The client requests the email, profile, and openid scopes.

Critical Security Standard: The Flutter client never sends access tokens to the backend. It only transmits the cryptographically signed OpenID Connect ID Token (JWT signed by Google's public keys).
Server-Side Laravel Verification & Provisioning

The Laravel backend receives the ID token at POST /api/v1/auth/google. Using the official google/apiclient library, Laravel verifies the token's signature, audience (matching client ID), issuer (https://accounts.google.com), and expiration.

Automatic User Provisioning: If the google_id does not exist, an account is created instantly with a UUID primary key, bound to the device's hardware UUID, and issued a scoped Laravel Sanctum Bearer token.

How Google Play Manages the Free Trial

The 7-day trial is configured in Google Play Console as an Introductory Offer on the base plans. When a user subscribes, Google Play creates a subscription token with paymentState = 2 (Free Trial). How Laravel Tracks Trial Period & Prevents Abuse

Upon receipt verification, Laravel marks status = 'trialing', setting trial_starts_at = NOW() and trial_ends_at = NOW() + INTERVAL 7 DAY. To prevent users from resetting trials by uninstalling the app or using different local accounts, the backend binds the trial history to the primary google_id and the device's hardware fingerprint (device_uuid).

Laravel Backend FCM v1 Service (`PushNotificationService.php`)

<?php

namespace App\Domains\Device\Services;

use Google\Client as GoogleClient;
use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Log;
use App\Domains\Device\Models\Device;

class PushNotificationService
{
    protected string $projectId;
    protected string $accessToken;

    public function __construct()
    {
        $this->projectId = config('services.firebase.project_id', 'lockguard-prod');
        $this->accessToken = $this->getGoogleAccessToken();
    }

    private function getGoogleAccessToken(): string
    {
        $client = new GoogleClient();
        $client->setAuthConfig(storage_path('app/google-service-account.json'));
        $client->addScope('https://www.googleapis.com/auth/firebase.messaging');
        $token = $client->fetchAccessTokenWithAssertion();
        return $token['access_token'];
    }

    /**
     * Send Silent Background Push to trigger instant entitlement sync
     */
    public function sendSilentEntitlementSync(Device $device): bool
    {
        if (!$device->fcm_token) return false;

        $url = "https://fcm.googleapis.com/v1/projects/{$this->projectId}/messages:send";

        $payload = [
            'message' => [
                'token' => $device->fcm_token,
                'data' => [
                    'action' => 'SYNC_ENTITLEMENTS',
                    'timestamp' => (string) now()->timestamp,
                ],
                'android' => [
                    'priority' => 'high',
                ],
            ],
        ];

        $response = Http::withToken($this->accessToken)->post($url, $payload);
        return $response->successful();
    }
}

    final bool available = await _iap.isAvailable();
    if (!available) throw Exception('Google Play Billing unavailable');

    final ProductDetailsResponse response =
        await _iap.queryProductDetails(allProductIds);
    if (response.error != null) {
      throw Exception(response.error!.message);
    }
    return response.productDetails;
  }

  /// Launch Google Play Purchase Sheet
  Future initiatePurchase(ProductDetails product) async {
    final PurchaseParam purchaseParam = PurchaseParam(productDetails: product);
    if (product.id == lifetimeProductId) {
      // Non-consumable One-Time Purchase
      await _iap.buyNonConsumable(purchaseParam: purchaseParam);
    } else {
      // Auto-renewing Subscription (with 7-Day Free Trial)
      await _iap.buyNonConsumable(purchaseParam: purchaseParam);
    }
  }

  /// Process Purchase Stream Events
  Future _onPurchaseUpdate(List purchaseDetailsList) async {
    for (final PurchaseDetails purchase in purchaseDetailsList) {
      if (purchase.status == PurchaseStatus.pending) {
        debugPrint('Purchase pending approval or card charge...');
      } else if (purchase.status == PurchaseStatus.error) {
        debugPrint('Purchase error: ${purchase.error?.message}');
        if (purchase.pendingCompletePurchase) {
          await _iap.completePurchase(purchase);
        }
      } else if (purchase.status == PurchaseStatus.purchased ||
                 purchase.status == PurchaseStatus.restored) {
        // ZERO-TRUST: Send token to Laravel backend for validation
        final bool verified = await _verifyWithBackend(purchase);
        if (verified && purchase.pendingCompletePurchase) {
          // CRITICAL: Must complete purchase to prevent Google refunding after 3 days
          await _iap.completePurchase(purchase);
        }
      }
    }
  }

  Future _verifyWithBackend(PurchaseDetails purchase) async {
    try {
      final googleDetails = purchase as GooglePlayPurchaseDetails;
      final response = await _apiClient.verifyPurchase(
        productId: purchase.productID,
        purchaseToken: googleDetails.billingClientPurchase.purchaseToken,
        orderId: googleDetails.billingClientPurchase.orderId,
      );
      return response.isSuccess;
    } catch (e) {
      debugPrint('Backend verification failed: $e');
      return false;
    }
  }

  void dispose() {
    _subscription.cancel();
  }

GooglePlayVerificationService (PHP 8.3)

Integrates with official google/apiclient using a Google Cloud Service Account JSON key. Calls Google Play Developer API v3 to verify tokens and fetch live subscription status. 

<?php

namespace App\Domains\Billing\Services;

use Google\Client as GoogleClient;
use Google\Service\AndroidPublisher;
use Google\Service\AndroidPublisher\SubscriptionPurchaseV2;
use Google\Service\AndroidPublisher\ProductPurchase;
use Exception;
use Illuminate\Support\Facades\Log;

class GooglePlayVerificationService
{
    protected AndroidPublisher $publisher;
    protected string $packageName;

    public function __construct()
    {
        $this->packageName = config('google.play_package_name', 'com.exciteon.lockguard');

        $client = new GoogleClient();
        $client->setAuthConfig(storage_path('app/google-service-account.json'));
        $client->addScope(AndroidPublisher::ANDROIDPUBLISHER);

        $this->publisher = new AndroidPublisher($client);
    }

    /**
     * Verify auto-renewing subscriptions (Monthly / Yearly)
     */
    public function verifySubscription(string $purchaseToken): array
    {
        try {
            /** @var SubscriptionPurchaseV2 $purchase */
            $purchase = $this->publisher->purchases_subscriptionsv2->get(
                $this->packageName,
                $purchaseToken
            );

            $subscriptionState = $purchase->getSubscriptionState();
            // States: SUBSCRIPTION_STATE_PENDING (1), SUBSCRIPTION_STATE_ACTIVE (2),
            // SUBSCRIPTION_STATE_PAUSED (3), SUBSCRIPTION_STATE_IN_GRACE_PERIOD (4),
            // SUBSCRIPTION_STATE_ON_HOLD (5), SUBSCRIPTION_STATE_CANCELED (6),
            // SUBSCRIPTION_STATE_EXPIRED (7)

            $lineItems = $purchase->getLineItems();
            $lineItem = $lineItems[0] ?? null;
            $productId = $lineItem ? $lineItem->getProductId() : null;
            $expiryTime = $lineItem ? $lineItem->getExpiryTime() : null;

            // Check if user is in 7-day free trial introductory offer
            $offerDetails = $lineItem ? $lineItem->getOfferDetails() : null;
            $isTrial = $offerDetails && in_array('free-trial', $offerDetails->getOfferTags() ?? []);

            $isActive = in_array($subscriptionState, [
                'SUBSCRIPTION_STATE_ACTIVE',
                'SUBSCRIPTION_STATE_IN_GRACE_PERIOD'
            ]);

            return [
                'is_valid' => $isActive,
                'state' => $subscriptionState,
                'product_id' => $productId,
                'is_trial' => $isTrial,
                'expires_at' => $expiryTime,
                'raw_response' => $purchase->toSimpleObject()
            ];
        } catch (Exception $e) {
            Log::error('Google Play Subscription Verification Error: ' . $e->getMessage());
            return ['is_valid' => false, 'error' => $e->getMessage()];
        }
    }

    /**
     * Verify one-time lifetime in-app product purchase
     */
    public function verifyOneTimeProduct(string $productId, string $purchaseToken): array
    {
        try {
            /** @var ProductPurchase $purchase */
            $purchase = $this->publisher->purchases_products->get(
                $this->packageName,
                $productId,
                $purchaseToken
            );

            // PurchaseState: 0 (Purchased), 1 (Canceled), 2 (Pending)
            $isPurchased = ($purchase->getPurchaseState() === 0);

            return [
                'is_valid' => $isPurchased,
                'order_id' => $purchase->getOrderId(),
                'consumption_state' => $purchase->getConsumptionState(),
                'raw_response' => $purchase->toSimpleObject()
            ];
        } catch (Exception $e) {
            Log::error('Google Play Product Verification Error: ' . $e->getMessage());
            return ['is_valid' => false, 'error' => $e->getMessage()];
        }
    }
}
ProcessGooglePlayRtdnJob (Async Worker)

Dispatched from the Pub/Sub webhook controller. Safely parses notification types, queries the Play API, updates the database, clears Redis cache, and emits push events. 

<?php

namespace App\Domains\Billing\Jobs;

use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\SerializesModels;
use App\Domains\Billing\Services\GooglePlayVerificationService;
use App\Domains\Billing\Models\UserSubscription;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Log;

class ProcessGooglePlayRtdnJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    protected array $data;

    public function __construct(array $data)
    {
        $this->data = $data;
    }

    public function handle(GooglePlayVerificationService $verifier): void
    {
        $subNotification = $this->data['subscriptionNotification'] ?? null;
        if (!$subNotification) return;

        $token = $subNotification['purchaseToken'];
        $notificationType = $subNotification['notificationType'];

        $subscription = UserSubscription::where('google_purchase_token', $token)->first();
        if (!$subscription) {
            Log::warning("RTDN received for unrecorded purchase token: {$token}");
            return;
        }

        // Notification Types:
        // 2: SUBSCRIPTION_RENEWED
        // 3: SUBSCRIPTION_CANCELED
        // 5: SUBSCRIPTION_ON_HOLD
        // 6: SUBSCRIPTION_IN_GRACE_PERIOD
        // 13: SUBSCRIPTION_EXPIRED
        switch ($notificationType) {
            case 2: // RENEWED
                $details = $verifier->verifySubscription($token);
                $subscription->update([
                    'status' => 'active',
                    'current_period_ends_at' => $details['expires_at'],
                    'auto_renewing' => true,
                ]);
                break;

            case 3: // CANCELED (User stopped renewal, but period remains active)
                $subscription->update(['auto_renewing' => false, 'cancelled_at' => now()]);
                break;

            case 5: // ON HOLD
                $subscription->update(['status' => 'on_hold']);
                break;

            case 6: // IN GRACE PERIOD
                $subscription->update(['status' => 'in_grace_period']);
                break;

            case 13: // EXPIRED (Subscription ended or trial cancelled without renewal)
                $subscription->update(['status' => 'expired']);
                break;
        }

        // Clear Cached Entitlements
        Cache::forget("user:{$subscription->user_id}:entitlements");
        Log::info("RTDN processed for user: {$subscription->user_id}, new status: {$subscription->status}");
    }
}

This job executes the user's explicit directive: "the backend sends the alert mail to each recipient along with all information. After that, the backend clears the media files from its storage. No cloud storage (no photos & videos of users stored anywhere)." 

<?php

namespace App\Domains\Alerts\Jobs;

use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\SerializesModels;
use Illuminate\Support\Facades\Mail;
use Illuminate\Support\Facades\File;
use Illuminate\Support\Facades\Log;
use App\Domains\Alerts\Mail\IntrusionAlertMailable;
use App\Domains\Alerts\Models\AlertLog;

class SendIntrusionAlertEmailJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    protected string $tempDirPath;
    protected array $metadata;
    protected array $recipients;
    protected string $alertId;

    public function __construct(string $tempDirPath, array $metadata, array $recipients, string $alertId)
    {
        $this->tempDirPath = $tempDirPath;
        $this->metadata = $metadata;
        $this->recipients = $recipients;
        $this->alertId = $alertId;
    }

    public function handle(): void
    {
        try {
            // 1. Scan staged ephemeral media files
            $photos = File::glob("{$this->tempDirPath}/photo_*.jpg");
            $frontVideo = File::exists("{$this->tempDirPath}/front_video.mp4") ? "{$this->tempDirPath}/front_video.mp4" : null;
            $rearVideo = File::exists("{$this->tempDirPath}/rear_video.mp4") ? "{$this->tempDirPath}/rear_video.mp4" : null;

            // 2. Dispatch multipart email via Backend SMTP Relay (Amazon SES / SendGrid)
            foreach ($this->recipients as $recipientEmail) {
                Mail::to(trim($recipientEmail))->send(
                    new IntrusionAlertMailable(
                        metadata: $this->metadata,
                        photoPaths: $photos,
                        frontVideoPath: $frontVideo,
                        rearVideoPath: $rearVideo
                    )
                );
            }

            // 3. Mark database audit record delivery status (Metadata ONLY - NO media stored)
            AlertLog::where('id', $this->alertId)->update([
                'delivery_status' => 'sent',
                'dispatched_at' => now(),
            ]);

            Log::info("Intrusion alert email successfully delivered to recipients: " . implode(', ', $this->recipients));

        } catch (\Exception $e) {
            Log::error("Failed to send alert email for alert {$this->alertId}: " . $e->getMessage());
            AlertLog::where('id', $this->alertId)->update(['delivery_status' => 'failed']);
            throw $e;

        } finally {
            // =========================================================================
            // ZERO-STORAGE GUARANTEE: IMMEDIATELY PURGE ALL MEDIA FROM BACKEND DISK
            // =========================================================================
            if (File::exists($this->tempDirPath)) {
                File::deleteDirectory($this->tempDirPath);
                Log::info("ZERO-STORAGE PURGE: Deleted ephemeral media directory: {$this->tempDirPath}");
            }
        }
    }
}
